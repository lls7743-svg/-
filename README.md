# 会話コーチ (Conversation Coach)

マイクで拾った会話をブラウザの音声認識でリアルタイムに文字起こしし、Claude API で分析して「その場で使える短いアドバイス」を表示するWebアプリです。友人や気になる相手との会話が、より円滑で好意的なものになるようサポートします。

## 特徴

- ブラウザ標準の Web Speech API で音声認識（追加費用なし、Chrome推奨）
- 発話に区切りがつくたびに直近の会話をサーバー経由で Claude に送信し、40〜70文字程度の短いアドバイスをリアルタイム表示
- 会話の雰囲気（良い / 普通 / 要注意）も簡易表示
- 開始前に相手の同意を得ることを促す同意画面を表示

## セットアップ

```bash
npm install
cp .env.example .env
# .env に ANTHROPIC_API_KEY を設定
npm start
```

ブラウザで `http://localhost:3000` を開き、マイクの利用を許可してください。

## 仕組み

1. `public/app.js` が `SpeechRecognition` で音声をテキスト化
2. 一定量の新しい発話がまとまるたび（最短7秒間隔）に `/api/advice` へ直近の文字起こしを送信
3. `server.js` が Anthropic API (`claude-sonnet-5`) にプロンプトを送り、JSON形式のアドバイスを取得してフロントエンドへ返却

APIキーはサーバー側でのみ使用され、ブラウザには渡りません。

## 注意事項

- このアプリは自分の端末のマイクを使って会話を分析するツールです。**会話相手の同意なく録音・分析に使用しないでください。**
- アドバイスはあくまで参考です。実際の言動は自分の判断で行ってください。

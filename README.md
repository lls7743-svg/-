# デイトレ・シミュレーター

仮想資金（初期 ¥1,000,000）で日本株のデイトレードを自動シミュレーションするツールです。
GitHub Actions が30分おきに実際の株価（Yahoo Finance / yfinance）を取得し、ルールベースの
売買AIが売買・利益確定・損切りを自動判断します。結果はWebダッシュボードでチャート上に
買い（▲）・売り（▼）のタイミングとして表示されます。**実際の資金は一切使用していません。**

## しくみ

```
GitHub Actions (30分毎, TSE取引時間中)
  → trader/run.py が株価取得 (yfinance)
  → trader/strategy.py が売買判断・実行
  → data/*.json を更新してコミット
  → index.html (GitHub Pages) が data/*.json を読んでチャート描画
```

- **対象銘柄**: `trader/config.py` の `WATCHLIST`（日経225相当の大型・流動株を中心に約160銘柄。
  公式の指数構成銘柄そのものではなく手動で集めた近似リストです）。毎サイクル全銘柄をスキャンし、
  シグナルが出た銘柄の中から一番勢いの強いものを選んで売買します（先頭から順に選ぶのではなく、
  条件に合う候補をランキングして上位から採用）。
- **売買判断**: ルールベースの疑似AI
  - **エントリー**: 短期移動平均(5)が長期移動平均(25)を上抜け（ゴールデンクロス）かつRSI<70の銘柄の中から、
    長期移動平均からの乖離が大きい（＝勢いが強い）順に、空いている建玉枠まで採用
  - **損切り**: エントリー価格から -3%
  - **利益確定**: +2%でトレーリングストップを発動し、そこからの高値-2%で利確（固定の利確ラインではなく、値動きに応じてタイミングを動的に決定）
  - **デッドクロス**: 短期MAが長期MAを下抜けたら手仕舞い
  - **大引け前手仕舞い**: 15:00(JST)以降は新規建てをせず、保有ポジションは強制的に手仕舞い（デイトレ運用のため）
- 資金配分は最大4銘柄、1銘柄あたり資産の20%まで、単元株（100株）単位

## セットアップ（初回のみ）

このリポジトリを使うには2つの設定が必要です。

1. **このブランチを default branch にマージする**
   GitHub Actions の `schedule` トリガーは default branch 上のワークフローファイルでしか
   発火しません。PRをマージするまで自動売買は始まりません。
2. **GitHub Pages を有効化する**
   Settings → Pages → Source を「Deploy from a branch」→ Branch: `main` / `(root)` に設定。
   数分後に `https://<user>.github.io/<repo>/` でダッシュボードが見られます。

あとは待つだけです。平日 9:00〜15:30 (JST) の間、30分おきに Actions が自動実行され、
`data/` 配下のJSONが更新・コミットされていきます。

### 手動実行 / 動作確認

Actions タブから `Day Trading Simulator` ワークフローを開き `Run workflow` で即時実行できます。

## ローカルでの確認

```bash
pip install -r requirements.txt
python -m trader.run          # 1サイクル実行（市場が開いていれば売買判断も行う）
pytest tests/                 # 戦略ロジックの単体テスト（ネットワーク不要）
python -m http.server 8000    # ダッシュボードを確認 (http://localhost:8000/)
```

`index.html` は `data/portfolio.json` などを `fetch()` で読むため、`file://` では
CORSでブロックされます。必ず簡易HTTPサーバー経由で開いてください。

## カスタマイズ

- 銘柄・資金・戦略パラメータ: `trader/config.py`
- 実行頻度: `.github/workflows/trade.yml` の `cron`（GitHub Actionsの最短間隔は5分程度が実用的な下限）
- 売買ロジック: `trader/strategy.py`

## 制限事項

- yfinanceの株価は取引所の遅延配信で、多くの場合15〜20分程度の遅延があります（証券会社の
  リアルタイム板情報ではありません）。
- 日本取引所グループ(JPX)の休場日カレンダーには対応していません（土日はスキップしますが、
  祝日は「データが取得できない/古い」場合にスキップされる想定です）。
- 売買判断は固定ルール（移動平均クロス・RSI・トレーリングストップ）による疑似AIであり、
  Claude自身がリアルタイムに市場を読んで判断しているわけではありません。

# daytrade_patterns

過去の株価チャート(実データ)を使って、複数の代表的なデイトレードパターンをバックテストし、
期待値・勝率・プロフィットファクター・最大ドローダウンなどで比較するツールです。

**重要な注意:** このツールを組み立てた Claude Code のサンドボックス環境は外部ネットワーク
(Yahoo Finance 等)にアクセスできないため、実際の株価データによる検証はこちらでは行えて
いません。ロジックは合成データでユニットテスト済みですが、**実データでの検証はご自身の
マシンで実行してください。**

## セットアップ

```bash
cd daytrade_patterns
pip install -r requirements.txt
```

## 実行方法

```bash
python main.py --tickers AAPL,MSFT,SPY,QQQ,TSLA --period 60d --interval 5m
```

主なオプション:

- `--tickers`: カンマ区切りの銘柄コード
- `--period` / `--interval`: yfinance の取得期間・足種。yfinance の制限で `1m` 足は直近7日
  分、`5m`/`15m` などの分足は直近60日分までしか取得できません
- `--patterns`: 検証するパターン名(カンマ区切り、デフォルトは `all`)
- `--risk-pct`: 1トレードあたり資金の何%をリスクに晒すか(資産曲線シミュレーション用)
- `--slippage-bps` / `--commission-bps`: スリッページ・手数料(bps)
- `--trades-out` / `--report-out`: 個別トレード・ランキング表をCSVに保存

出力は各パターンの `勝率 / プロフィットファクター / 期待値(R) / トータルリターン / 最大
ドローダウン / シャープレシオ` を期待値順にランキングした表です。

## 実装しているパターン

| パターン | 概要 |
|---|---|
| `orb_breakout` | オープニングレンジブレイクアウト。寄り付き最初のN分の高安を突破したら順張りエントリー |
| `gap_and_go` | ギャップアップ/ダウンで寄り、初動と同方向に最初の5分足を突破したらエントリー |
| `vwap_reversion` | VWAPを挟んだ押し目/戻り。トレンド方向にVWAPへタッチしてから再度トレンド方向にクローズしたらエントリー |
| `ema_crossover` | 短期EMA(9)が長期EMA(20)をクロスしたらエントリー(順張り) |
| `rsi2_mean_reversion` | 短期RSI(2)が極端な水準まで振れた翌足で逆張りエントリー(Larry Connors型) |
| `bollinger_breakout` | ボリンジャーバンドのスクイーズ(直前バーのバンド幅が過去中央値以下)後のブレイクアウト |

いずれも1日1回・1銘柄1トレードまでに制限しています(パターン間の比較を公平にするため)。
エグジットは「損切り/利確どちらかにヒット、なければ大引けで手仕舞い」のルールで、当日中に
必ず手仕舞う前提(オーバーナイトは保有しない)です。

## ランキングの見方

**勝率だけで判断しないでください。** 勝率が低くても平均利益が平均損失より大きければ
期待値はプラスになり得ます。このツールは `expectancy_r`(1トレードあたりの平均R倍数)を
主指標にランキングしています。`profit_factor`(総利益/総損失)や `max_drawdown_pct` も
必ず併せて確認してください。

## 制限事項・注意点

- パラメータ(オープニングレンジの分数、EMA期間、RSI閾値など)は一般的な値を仮置きした
  ものです。特定の銘柄・時間帯・ボラティリティ環境に対して最適化(過学習)されたもの
  ではありません。パラメータを変えて検証結果がどれだけ変わるかも必ず確認してください。
- サンプル数(トレード数)が少ないパターン・銘柄の結果は統計的に信頼できません。複数銘柄・
  長期間で検証し、`n_trades` が十分(できれば数十〜百以上)あるかを確認してください。
- スリッページ・手数料は簡易的なbpsモデルです。実際の執行コスト(板の薄さ、成行/指値の差、
  ボラティリティ急変時のスリッページ)はもっと大きくなり得ます。
- 過去のパターンが将来も機能する保証はありません。本ツールは教育・研究目的であり、
  投資助言ではありません。実資金での運用前に十分なフォワードテスト・少額での検証を
  行ってください。

## テスト

合成データでロジックの妥当性を検証しています(実データの取得なしで実行可能):

```bash
python -m pytest tests/ -v
```

## ディレクトリ構成

```
daytrade_patterns/
  main.py              CLIエントリポイント
  src/
    data.py             yfinanceからの取得・キャッシュ・セッション分割
    indicators.py        EMA / RSI / VWAP / ボリンジャーバンド / ATR
    patterns.py           各デイトレードパターンのシグナル検出
    backtest.py           トレードシミュレーション・成績集計
  tests/                合成データによるユニットテスト
  data_cache/           取得データのCSVキャッシュ(gitignore対象)
```
